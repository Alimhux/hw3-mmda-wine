# Рекомендательная система вин

Приложение для части 4 ДЗ: по 12 характеристикам вина показывает вероятность хорошего качества и решение модели. Хорошее вино — экспертная оценка не ниже 7.

## Запуск

Проверено с **Python 3.13.5**. В папке должны лежать `app.py`, `model.joblib`, `config.json`, `test.csv` и `requirements.txt`. Модель, порог и test сохраняются в ноутбуке, в ячейке «Сохранение модели». Пайплайн обучен только на train, порог выбран по валидации.

Из папки `wine_app`:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows вместо `source` используется `.venv\Scripts\activate`. Из родительской папки можно запустить `python -m streamlit run wine_app/app.py`: файлы ищутся относительно `app.py`, а не текущей директории.

## Как пользоваться

- «Одно вино»: 11 числовых полей и переключатель красного/белого вина. Начальные значения — медианы test, границы — минимум и максимум test.
- «Модельные метрики»: матрица ошибок, precision, recall, F1, ROC и PR. Оранжевая точка показывает текущий порог. PR-AUC здесь считается через average precision.
- «Пакетное предсказание»: CSV с теми же признаками. Есть пример файла и скачивание результатов. Отсутствующие столбцы, текст вместо чисел, пропуски и неверный is_red дают понятную ошибку.
- «Что выучила модель»: коэффициенты логистической регрессии после масштабирования.

Порог в сайдбаре общий для всех вкладок и хранится в `st.session_state`. Начальное значение читается из `config.json`. Класс 1 присваивается при `probability >= threshold`. Если ни одно вино не выбрано, precision показывается равным 0, а причина подписывается возле графика.

Тест здесь нужен для оценки и демонстрации; выбирать по нему новую модель или порог нельзя. В приложении нет `fit` и переобучения. Небольшие изменения порога не обязаны менять метрики: если между двумя порогами нет предсказанных вероятностей, решения останутся прежними.

## Деплой на Streamlit Community Cloud

1. Поместить папку `wine_app` с моделью, конфигом, test и зависимостями в GitHub-репозиторий.
2. В [Streamlit Community Cloud](https://streamlit.io/cloud) создать приложение из этого репозитория, выбрать ветку и файл `wine_app/app.py`.
3. В настройках окружения выбрать Python 3.13 и дождаться установки зависимостей. При экспорте модели и на сервере нужны одинаковые версии scikit-learn и imbalanced-learn.
4. Проверить все четыре вкладки по публичной ссылке и добавить эту ссылку в ноутбук.

Приложение опубликовано на Streamlit Community Cloud: [открыть приложение](https://alimhux-hw3-wine.streamlit.app).

Исходники и файлы модели: [GitHub-репозиторий](https://github.com/Alimhux/hw3-mmda-wine). В облачной версии проверены предсказание одного вина и изменение метрик при смене порога.
